# HR-Analytics-Project-Power-BI-
Developed an interactive HR Attrition Analysis Dashboard built in Power BI! This project analyzes employee attrition trends across gender, age group, tenure, salary slab, and job roles. It helps HR teams identify key areas of turnover and make data-driven decisions for retention strategies.  ⚙️ Tools &amp; Skills: Power BI | DAX | Data Modeling | KPI
